# RedNightClock

An Android night clock application designed to display time in a dreamy ambient format.

## Features

- **Clock Display**: Clean clock view with customizable styling
- **Dream Service**: Ambient display mode for nighttime viewing
- **Battery Indicator**: Shows charging status
- **Boot Receiver**: Automatically starts on device boot
- **Preferences**: User-configurable settings

## Building

This project uses Gradle with Android Gradle Plugin 8.13.0.

```bash
./gradlew build
```

## Requirements

- Android SDK 36
- Min SDK 26 (Android 8.0)
- Java 17

Current version: 1.3 ( versionCode: 4 )
